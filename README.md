# Платформа данных (frontend)

Веб-интерфейс SaaS-платформы для сбора информации с разных источников данных.
Работает без сборки: чистые HTML, CSS и JavaScript.

## Возможности

- Вход в личный кабинет (демо-доступ: `demo` / `demo`, если бэкенд недоступен)
- Дерево источников и таблиц с поиском
- Просмотр структуры таблицы и её данных (сортировка, постраничный вывод)
- Скачивание таблиц в CSV и Excel
- Макет чата с ИИ-помощником (ответы пока не настоящие)

## Запуск

Откройте `index.html` в браузере двойным кликом.
Для работы с бэкендом (запросы к `/api`) страницу нужно открывать через сервер:

```bash
npx serve .
```

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка страницы |
| `styles.css` | оформление |
| `app.js` | логика: данные, вход, таблицы, скачивание, чат |

## API (ожидаемые эндпоинты)

- `POST /api/auth/login` `{username, password}` → `{token}`
- `GET /api/sources` → `[{id, name, tables: [{name, columns: [{name, type}]}]}]`
- `GET /api/sources/:id/tables/:name/rows` → `[{...}]`

Перед продакшеном поставьте `DEMO = false` в начале `app.js`.
